# DoctorTracer

Локальная векторизация изображений: Windows-приложение с пошаговым мастером и отдельная экспериментальная WASM-версия. Изображения остаются на компьютере пользователя.

## Windows

Portable-сборка: **Releases → v0.6.0 → DoctorTracer-0.6-Windows-x64.zip**. Распакуйте весь архив и запустите `DoctorTracer.exe`. Python для portable-сборки не нужен.

Запуск исходников (Python 3.13, Windows x64):

```powershell
python -m pip install -r desktop/requirements.txt
python desktop/app.py
```

Ветка `spatial-photo-preview`: Windows **0.10 preview** — новый режим фотографий с общими границами,
адаптивным объединением областей и GPU-фильтрацией.
[Сравнение и проверки](docs/PHOTO_REGIONS.md). Версия 0.9 добавила объединение фрагментов
одного цвета, PDF для CorelDRAW, новые иконки и GPU-предобработку. [Проверки и ограничения](docs/COREL_IMPORT.md).
Предыдущая 0.8 добавила группы SVG по цветам,
устранение наложений геометрии, исправление пропадающих цветов и экспериментальная
пространственная сегментация фото с ограниченной палитрой. Настройки доступны
в «Дополнительные Параметры»; цветовые группы и устранение наложений
применяются всегда. В 0.9 пространственная сегментация и GPU включены по умолчанию.
[Точность и ограничения](docs/VECTOR_LAYOUT.md),
[проверки GPU-сегментации](docs/SPATIAL_PALETTE.md).
Стабильный выпущенный архив 0.6 остаётся доступен; WASM не изменён.

0.10.1 preview добавляет процент и название этапа обработки из рабочего процесса.
Страница сохранения помещается по ширине панели, в том числе при раскрытых разделах;
на небольших окнах все поля доступны через вертикальную прокрутку.

0.10.2 preview исправляет структуру PDF для CorelDRAW: общая группа изображения →
подгруппы по RGB → отдельные кривые. Отверстия сохраняются вместе с внешним контуром.
Старые PDF нужно повторно экспортировать новой версией. [Проверка импорта](docs/COREL_GROUPS.md).

Сборка: `powershell -File desktop/build.ps1`.

Поддерживаются иллюстрации/фотографии, редактирование палитры, три качества, расширенная сегментация и сглаживание, редактор областей, удаление фона, пакетная обработка, SVG/EPS/PDF/PNG. В дополнительных параметрах выбирается CPU/OpenCL GPU. GPU ускоряет фильтрацию и распределение пикселей по цветам, включая новый режим фотографий без ограниченной палитры. Объединение областей, построение общих границ и проверка пересечений работают на CPU. Без GPU используется CPU.

## Изменение построения кривых в 0.6

В фоторежиме короткие ступенчатые сегменты теперь заново аппроксимируются оптимизированными кривыми Безье через native Potrace DLL. Цветовая сегментация и порядок слоёв сохранены. Это исправляет угловатость при увеличении, но не делает области идентичными оригиналу. Есть дополнительная стоимость CPU: около 1,5 с для среднего качества контрольной акварели. Подробности: [CURVES.md](docs/CURVES.md).

Проверка нового этапа: `python tests/photo_curves.py`. Пересборка DLL: Zig 0.15.2 на PATH, затем `python scripts/build_potrace_dll.py`; готовая DLL включена.

## WASM preview (разработка отложена)

Запустите `python scripts/serve.py` или `start-web.cmd`, откройте **http://127.0.0.1:8765**. Локальный сервер нужен для ES-модулей и WASM, изображения он не принимает. Внешние CDN не требуются.

Тип изображения в WASM задаёт начальную палитру: фото — 64, иллюстрация — 16, чистые края — 8 цветов; все типы используют общий движок. Работают открытие PNG/JPEG/WebP/BMP, мастер настроек, 2–128 цветов, прозрачность/белый фон, три качества, кривые/полигоны, Bitmap/Вектор/Контуры, масштаб, отмена и SVG.

**Предварительная версия:** отдельное ядро с ограниченной палитрой и Potrace. Не перенесены неограниченные цвета фотографий Windows, OpenCL, редактор областей, пакетная обработка и EPS/PDF. Результаты Windows и WASM различаются. Максимальная сторона обработки в браузере — 2400 px, альфа бинарная с порогом 128/255.

Пересборка с активированным официальным Emscripten **4.0.23**:

```powershell
python scripts/build_wasm.py
node tests/wasm.mjs
```

## Сходство с оригиналом

Интерфейс и сценарии исследованы по установленной Vector Magic Desktop Rus 1.15 через REA и интерфейс программы. Реализация независимая. **Почти полная идентичность пока не достигнута.**

На контрольной акварели 800×954 в режиме «Фото → оставить прозрачность → цвета без ограничений» версия 0.5 уменьшила MAE относительно 0.4 на 2–6% на белом и 24–28% на тёмном фоне. IoU силуэта: 0.9845–0.9855 вместо 0.9587–0.9595. Это одно изображение, не универсальная оценка. См. [методику](docs/COMPARISON.md) и [измерения](docs/photo-comparison.json).

Пользовательские изображения, эталонные SVG и компоненты оригинала не публикуются. Сравнить свои результаты:

```powershell
python desktop/compare_reference.py reference.svg candidate.svg --width 800 --height 954
```

## Проверки

```powershell
python tests/desktop_smoke.py
node tests/wasm.mjs
```

Проверяются прозрачность, внутренние белые области, CPU/GPU либо fallback, три качества фото, сведение на белый, повторные задания Unicode-процесса, детерминизм WASM и полигоны. Windows-мастер дополнительно проверен локально на 36 сочетаниях страниц и размеров окна.
