DoctorTracer — справка

Откройте изображение, выберите режим, тип, качество и палитру. На странице результата доступны оригинал (B), вектор (V), контуры и масштаб.

SVG и PDF сохраняют цветовые группы. В PDF: общая группа изображения → группы цветов → кривые. PNG — растровая копия результата.

WebGPU ускоряет фильтрацию, если поддерживается браузером. Остальные этапы выполняет Rust WASM. При недоступности GPU используется CPU.

Это предварительная браузерная версия: результат пока отличается от Windows и Vector Magic. Прозрачность обрабатывается с порогом 128/255. Изображения свыше 2400 пикселей по стороне уменьшаются.
