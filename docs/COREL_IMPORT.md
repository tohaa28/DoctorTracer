# Windows 0.9 preview — исправление блоков и PDF для CorelDRAW

## Подтверждённая ошибка 0.8

Участки 128×128 после булевой обработки оставались отдельными объектами конечного
изображения. SVG-группа по RGB не объединяла их геометрию. Кроме того, PDF через
Qt записывал независимые пути, теряя семантику цветовых групп. Поэтому проверки
одного SVG/XML и отсутствия перекрытий были недостаточны для импорта в Corel.

Теперь после пространственных операций выполняется объединение фрагментов
одного RGB. Внутренние границы участков удаляются. Для изображения, помещающегося
в один участок, сохраняются исходные кривые — дополнительная полигонализация
не нужна. Ограничения линейного резервного алгоритма на сложных изображениях
пока сохраняются; идентичность Vector Magic не достигнута.

## PDF

Новый векторный PDF-экспорт записывает один Form XObject на RGB. Каждый содержит
один составной заполненный путь с отверстиями. Нет растровых подложек и отдельных
PDF-объектов для каждого блока. Размер документа и координаты сохраняются.

**Проверено через интерфейс установленного CorelDRAW 26 на Windows, 25.10.2026:**
PDF контрольного льва с 8 непрозрачными RGB успешно открыт как кривые. После
разгруппировки внешнего контейнера Corel показывает **8 выделенных объектов**.
Скриншот и пользовательский PDF остаются локально, вне репозитория.

Объединённый сложный SVG может превышать лимит количества элементов пути
парсера Qt SVG. Добавлена прямая отрисовка собственных цветовых объектов через
QPainterPath. Она используется в просмотре, PNG и выборе объектов. Стандартные
SVG-иконки остаются на обычном Qt SVG renderer. Проверен большой составной путь
из 8192 несвязанных квадратов: все видимы, цвет и прозрачность сохранены.

## GPU

В интерфейсе по умолчанию выбран OpenCL GPU с CPU fallback. Пространственная
сегментация ограниченной палитры фото включена; прежний переключатель позволяет
её отключить. Добавлен GPU-фильтр предварительной обработки: целочисленный
bilateral с сохранением alpha и исключением невидимых соседей. Его CPU-референс
и OpenCL дают побитово одинаковый результат. Он заменяет прежний OpenCV-фильтр
при включённом подавлении шума/пространственной сегментации.

**Не все расчёты перенесены на GPU.** GPU выполняет новый фильтр, назначение
палитры и пространственные проходы. Поиск палитры, mean shift/VTracer для фото
без ограничения цветов, кривые, булевы операции и PDF-сериализация остаются CPU.
Существующие Skia/Clipper-библиотеки не становятся GPU-реализациями от выбора
устройства. Полный перенос требует отдельного ядра и проверок корректности.

## Сравнение с оригиналом

Сохранённые эталоны Vector Magic Desktop Rus 1.15 сравниваются на том же
пользовательском входе 800×954, с теми же явными RGB и прозрачностью. UI6 означает
5 непрозрачных цветов и прозрачность; UI9 — 8 непрозрачных цветов и прозрачность.
Изображение и SVG остаются локально. Агрегаты — `corel-comparison.json`.

| Режим | Пути оригинала | Пути 0.9 | MAE белый | MAE тёмный |
|---|---:|---:|---:|---:|
| UI6, среднее | 3262 | 3315 | 3.817 | 3.510 |
| UI9, высокое | 2798 | 5311 | 4.216 | 4.037 |
| UI9, среднее | 4306 | 5280 | 4.402 | 4.136 |
| UI9, низкое | 6872 | 5007 | 4.879 | 4.234 |

Для всех восьми конфигураций проверки (пространственный алгоритм включён/выключен)
CPU и GPU выдали идентичные SVG. **Идентичность оригиналу не достигнута:** различаются
цветовые области и геометрия. Одно изображение и MAE не доказывают общего качества.
Замер нового фильтра на GTX 1080: медиана пяти прогретых повторов с передачами —
3.46 мс GPU, 738.54 мс CPU-референс на NumPy. Это не сравнение с прежним быстрым
OpenCV-фильтром и не ускорение всей трассировки в 200 раз.

## Иконки и проверки

Пиктограммы мастера заменены единым набором собственных векторных рисунков:
папка/импорт, буфер, пакет файлов, автоматика, настройки, фотография, типы края,
уровни детализации, палитры и сохранение. У кнопок качества — уровни детализации
вместо стрелки сброса. Палитра без ограничений отличается от фиксированной.

```powershell
python tests/color_objects.py
python tests/gpu_filter.py
python tests/vector_partition.py
python tests/desktop_smoke.py
python tests/spatial_palette.py
python tests/spatial_ui.py
python tests/photo_curves.py
```

Проверяются удаление внутренних границ блоков, один PDF-объект на цвет, чисто
векторный PDF, большой путь предпросмотра, 15 реальных CPU/GPU-тестов фильтра,
100 тестов пространственной сегментации, отверстия и реальные рабочие процессы.
Дополнительно проверяются сценарии мастера/экспортов и 36 вариантов компоновки.
WASM не изменялся.
