# Высокое качество небольших логотипов

Windows **0.17.0-preview**, WASM **0.19.0-wasm-preview**, 29.10.2026.

На присланном NF.png (163×122) прежняя сегментация теряла тонкую внутреннюю овальную линию, а локальное округление делало звёзды и засечки тупыми. Увеличение сглаживания не возвращает линию, исчезнувшую до построения векторов.

## Изменение

В высоком качестве AA-графики добавлен консервативный путь для небольших непрозрачных изображений с двумя красками. По RGB восстанавливается доля покрытия чернилами. Слабые краевые пиксели служат свидетельством тонкой линии, а не самостоятельной краской.

Модуль Rust `logo.rs` обнаруживает замкнутые эллиптические контуры на мягком пороге, проверяет их геометрию, затем подбирает вложенные эллипсы непосредственно по покрытию исходных пикселей. Изолированные пятиконечные звёзды подбираются по полному локальному отпечатку. Неуверенные модели не принимаются. Остальная графика трассируется в масштабе 8× Potrace 1.16. В эталонный PDF алгоритм не заглядывает; имя файла не участвует в выборе пути.

Подложка строится как точное векторное дополнение переднего плана: используются те же отрезки и контрольные точки в противоположном направлении. Rust проверяет парность всех интерфейсов, включая внешнюю грань. Независимый аудит проверяет пересечения. При отказе используется прежний общий граф. Сохраняются две цветовые группы PDF и полностью векторный экспорт.

Реализация одна для Windows DLL и WASM. Подбор моделей выполняется на CPU в Rust. Имеющиеся GPU-операции других ветвей сохранены. Точная пиксельная графика, прозрачность, фотографии, многоцветная графика и среднее/низкое качество сохраняют прежний путь. Размер ограничен 512×512; повёрнутые эллипсы не восстанавливаются этой моделью.

## Сравнение NF с Vector Magic

Входы и результаты пользователя остаются локально. [Числа](LOGO_HIGH_019_RESULTS.json).

Оба PDF отрисованы одним Poppler в 1630×1220, без подгонки позиции или масштаба. Синяя маска: B−R > 20. Единица расстояния — пиксель исходника.

| Метрика | До | После |
|---|---:|---:|
| IoU синей маски | 91,751% | 96,651% |
| Несовпадающие пиксели при 10× | 36 115 | 14 556 |
| Среднее симметричное расстояние границ | 0,178 | 0,055 |
| 95-й процентиль расстояния границ | 0,600 | 0,200 |
| Контуры в SVG, с учётом обеих сторон | 199 | 33 |

Восстановлены две овальные рамки и четыре острые звезды. На Windows обработка около 1,3 с. Это существенное сближение, а не побайтное повторение Vector Magic: изгибы букв, засечки и орнамент ещё отличаются. IoU не означает «процент качества» и не является оценкой всех изображений.

## Проверки

`tests/logo_reconstruction.py` и `.mjs`: кольца, звёзды, сочетание моделей, локальный NF; отказ от специального пути на точных пикселях, прозрачности и обычной фигуре без модели. В Windows/WASM совпали числа распознанных моделей, прошли контракт границ и аудит. Разница RGBA при 4×: 0 для трёх синтетических входов и 0,01051/255 для NF (разная точность печати координат адаптеров Potrace).

Повторены shared_contract, shared_routes, aa_support, pdf_color_groups, post_clean и диалоги дополнительных модулей. Полная прежняя матрица сравнений с Vector Magic заново не запускалась.
