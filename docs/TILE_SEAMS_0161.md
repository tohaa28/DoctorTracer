# WASM 0.16.1: удаление границ вычислительных квадратов

28.10.2026. В 0.16 целочисленное разбиение на участки 128×128 возвращало составной контур каждого цвета с внутренними границами квадратов. При экспорте/разделении контуров они становились отдельными объектами и могли давать сетку швов.

После вычитания перекрытий выполняется глобальный nonzero union всех фрагментов каждого цвета. Он удаляет внутренние рёбра и сохраняет отверстия; расширение областей и маскирующие обводки не используются. Вычислительные участки остаются внутренней деталью. Итоговые SVG/PDF/EPS получают уже объединённые границы. Windows 0.14 уже выполняет этот этап через merge_colors; новый тест проверяет его отдельно, выпуск Windows не меняется.

Проверки: tests/tile_seams.mjs — сплошная область, соседние области одного цвета, отверстие через несколько участков, два пересекающихся цвета. Удалены внутренние вершины сетки, площадь совпадает точно, нет пересечений. tests/tile_seams.py подтверждает то же для Windows. tests/audit_tiles.py — 16 прежних случаев, включая отверстия и пороговые пересечения; tests/pdf_color_groups.py — PDF-группы и отверстия.

Повторная трассировка astronaut, Chelsea и OpenMoji butterfly в режиме рисунка / 9 слотов: нет регрессий относительно VM по прежним порогам. Независимый целочисленный XOR старого/нового покрытия: 0 px² на двух фотографиях, 0.000000130751215 px² на рисунке. MAE относительно VM во всех трёх случаях неизменна. Число замкнутых подконтуров сократилось соответственно 3202→2941, 4358→4099, 158→145: удалены разрезы, а не детали изображения. Манифесты исходников и лицензии прежнего набора сохранены; изображения/экспорты VM не публикуются.

Локальный отчёт: build/quality-public-v2/reports/wasm-seams-0161/index.html. Исправление не заявляет устранение остальных известных ограничений 0.16.
