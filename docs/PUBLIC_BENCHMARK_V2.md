# Внешний испытательный стенд v2 — 26.10.2026

Проверены 12 новых изображений, четыре профиля, 48 настоящих экспортов Vector Magic Desktop 1.15 и по 48 независимых результатов DoctorTracer Windows и WASM. Покрытие полное; равенство качества не достигнуто. Код трассировки этим изменением не менялся. Версии приложения остаются Windows 0.12.0-preview / WASM 0.14.0-wasm-preview.

## Входы и воспроизводимость

`quality/public_sources.json` фиксирует полные коммиты, пути, SHA-256 и лицензии. Четыре фотографии scikit-image (astronaut, coffee, chelsea, rocket), четыре рисунка OpenMoji (fox, butterfly, palette, rocket), два Twemoji (flower, unicorn), две схемы Bootstrap Icons (qr-code, diagram-3). Лицензии: public domain/CC0, CC-BY-SA-4.0, CC-BY-4.0 и MIT соответственно; индивидуальные сведения сохранены в ATTRIBUTION.md корпуса. Исходники скачаны из GitHub через Contents API с проверкой Git blob SHA-1 и SHA-256. Фотографии уменьшены до максимум 640 px без увеличения; восемь SVG сначала растеризованы в 768×768, затем уменьшены Lanczos до 256×256 с сохранением альфа.

Набор выбран до запусков кандидатов. Теперь он уже использован для диагностики и не является невидимым holdout для будущей настройки. Это маленький набор из четырёх семейств, а не случайная репрезентативная выборка.

Профили: photo-medium-auto, photo-high-auto, photo-medium-9, graphic-medium-9. Соответствуют типу входа 20 комбинаций; ещё 28 намеренно проверяют другой тип трассировки. Их нельзя смешивать в единственную оценку обычного качества.

Эталоны получены пакетной обработкой установленной VM 1.15. Для каждого из четырёх запусков сохранён снимок настроек: фото либо рисунок со смешиванием, Medium/High, свободная палитра либо лимит 9, сохранение прозрачности, SVG. Экспорты зарегистрированы с хешами источника, SVG и снимка. Это пакетный путь, а не утверждение о проверке каждого шага базового мастера.

У кандидатов ограниченная палитра сформирована по реальному пути интерфейса: предложение по исходнику размером до 500 px, затем явный RGB-список ядру. Прозрачность занимает один из девяти слотов и исключается из RGB. Одинаковый лимит не означает одинаковые выбранные RGB или обязательное заполнение всех слотов. Палитра VM не передавалась независимым запускам. CPU выбран явно для воспроизводимости; эта серия не проверяет ускорение GPU.

## Метрики

- RGB MAE после наложения на белый и тёмный фон, альфа и IoU силуэта.
- Границы цветовых областей независимо от RGB: семантические метки заливок, допуск F1 один исходный пиксель, средняя и P95 дистанции. Эта геометрическая метрика намеренно игнорирует opacity; альфа проверяется отдельно.
- Топология силуэта и, при числе цветов не более 24, компонентов/отверстий каждого цвета. Сумма отверстий по цветам не равна числу прозрачных отверстий.
- Симметричная средняя ближайшая дистанция палитр ΔE76: без весов площадей и без взаимно однозначного назначения; не заменяет оценку изображения.
- Для восьми рисунков — независимое сравнение обоих экспортов с известным исходным SVG при ×4. MAE здесь также чувствительна к цветам, поэтому её нельзя считать чистой ошибкой кривых.
- Пути/команды SVG и время кандидата сохранены. Сопоставимого времени VM на каждом входе нет; рейтинг скорости не строился. Отсутствие baseline не превращает пустой список regressions в доказательство качества.

## Результаты на соответствующем типе входа

MAE в шкале 0–255, меньше лучше. F1 границ без RGB, больше лучше.

| Профиль / вход | N | MAE Windows | MAE WASM | F1 Windows |
|---|---:|---:|---:|---:|
| graphic-medium-9 / рисунки | 6 | 0.832 | 0.832 | 0.9984 |
| graphic-medium-9 / схемы | 2 | 0.226 | 0.226 | 1.0000 |
| photo-high-auto / фото | 4 | 3.834 | 3.834 | 0.8405 |

При лимите девять VM использовал на OpenMoji fox/butterfly по четыре RGB-цвета, DoctorTracer — восемь. На фото astronaut ошибка ограниченной палитры Windows составила 13.767, coffee — 11.090. Свободная палитра ближе, но совпадения с оригиналом тоже нет.

При ×4 относительно восьми исходных SVG средняя MAE VM — 0.193, Windows — 0.820. На QR DoctorTracer точнее: 0.000 против примерно 0.160 у VM. Высокая F1 с допуском один пиксель не гарантирует совпадения на увеличении.

### Отдельная диагностика с палитрой эталона

В отдельном условном опыте RGB из VM переданы DoctorTracer для четырёх фотографий photo-medium-9. Средняя MAE Windows снизилась с 10.084 до 1.849. Это **oracle-диагностика**, исключённая из независимых результатов: алгоритм не улучшен и эталонные цвета ему в обычной работе неизвестны. Опыт показывает большой вклад выбора палитры в расхождение, но не доказывает, что остальные стадии совпадают.

### Windows / WASM

Средняя RGBA MAE между версиями — 0.002979. Один из 48 случаев превышает прежний допуск: bootstrap-qr-code--photo-medium-auto, 0.041145 при пороге 0.02. Это стрессовый фото-профиль на QR, но ошибка не скрыта. Все 20 комбинаций соответствующего типа прошли этот тест. Для graphic-профилей допуск 0.25. Это отдельная проверка переносимости, не равенства с VM.
