# Windows 0.7 preview: пространственная сегментация фото

Новый алгоритм **экспериментальный и выключен по умолчанию**. Включение:
«Дополнительные Параметры → Экспериментальная сегментация фото с палитрой».
Затем выберите «Фотография» и ограниченную палитру и пересчитайте результат.
Режим учитывается в сохранённых настройках. Изменение опции блокирует экспорт
устаревшего результата. Фото без ограничения цветов и иллюстрации используют
свои прежние алгоритмы.

В этой сборке также исправлено исчезновение целых цветов в Qt SVG: Potrace CLI
теперь сохраняет отдельные связанные компоненты с их отверстиями, вместо одного
огромного пути на каждый цвет (`--flat`). Проверка 5452 компонентов подтверждает
полное покрытие и сохранение отверстия. Это исправление включено постоянно.
Расширенный мастер больше не заменяет выбранную категорию `photo` на `aa`.

## Независимый алгоритм

Для ограниченной палитры фото применяется bilateral-предобработка, целочисленная
RGB-классификация и два прохода пространственной оптимизации. Стоимость метки —
квадрат RGB-расстояния плюс штраф 700 за каждого из четырёх непрозрачных соседей
другого цвета. Обновления двух шахматных подмножеств выполняются последовательно.
При равной стоимости выигрывает первый цвет палитры. Прозрачные соседи не
участвуют, alpha <128 получает метку 255. После этого прежняя очистка мелких
областей применяется с минимальным порогом 8 пикселей и строятся кривые Potrace.

OpenCL выполняет начальное назначение и все пространственные проходы без
промежуточной выгрузки меток; итоговая карта скачивается один раз. Bilateral,
поиск палитры, связные компоненты и кривые остаются на CPU. При ошибке OpenCL
полная операция повторяется на CPU с записью причины. Это самостоятельная
гипотеза сегментации, не утверждение об устройстве Vector Magic.

API-настройки: `photo_spatial=true`, необязательные `spatial_strength` (0..100000,
по умолчанию 700), `spatial_iterations` (0..20, по умолчанию 2). Снижение штрафа
сохраняет больше локальных цветовых переходов; повышение может удалить слабые
тонкие детали. Нулевой штраф не отключает предобработку и очистку всего режима.

## Измеренное сравнение

Один пользовательский вход 800×954, одинаковые явные RGB в обеих программах,
фоторежим базового мастера, прозрачность. UI6 = пять непрозрачных цветов плюс
прозрачность; UI9 = восемь плюс прозрачность. Эталон Vector Magic Desktop Rus 1.15.
Контрольный вариант ниже уже содержит исправление пропадающих цветов.

| Палитра / качество | Пути эталона | Контроль → эксперимент | MAE белый | MAE тёмный |
|---|---:|---:|---:|---:|
| UI6 / среднее | 3262 | 7047 → 3102 | 4.844 → 3.947 | 4.307 → 3.600 |
| UI9 / высокое | 2798 | 9610 → 5002 | 5.417 → 4.446 | 5.038 → 4.216 |
| UI9 / среднее | 4306 | 9570 → 4962 | 5.517 → 4.583 | 5.097 → 4.255 |
| UI9 / низкое | 6872 | 8026 → 4682 | 5.287 → 5.020 | 4.540 → 4.339 |

Количество путей не является оценкой качества. В частности, эксперимент в низком
качестве даёт меньше областей, чем эталон. Соответствие поведения трёх качеств,
общие границы цветов, тонкие детали и независимый корпус ещё требуют исследования.
Ни идентичность, ни качество «не хуже оригинала» этими измерениями не доказаны.
Пользовательский вход, эталонные SVG и сравнительные PNG не публикуются.
Агрегаты — `spatial-comparison.json`.

На GTX 1080, драйвер 581.57, новая операция назначения для 800×954 / 8 цветов:
пять тёплых повторов с передачами памяти, медиана GPU 4.456 мс (p95 5.503),
CPU-реализация 1427.022 мс (p95 1462.736). Это цена **нового пространственного
алгоритма**, не ускорение всего приложения или прежнего nearest-color backend.
Начальная компиляция и загрузка файла не входят. RTX 3050 не измерена.

## Проверки

```powershell
python tests/palette_components.py
python tests/spatial_palette.py
python tests/spatial_ui.py
python tests/desktop_smoke.py
python tests/photo_curves.py
```

На доступной GTX 1080 прошли 100 побитовых CPU/GPU-проверок нового ядра (размеры
1×1, 1×37, 39×1, 17×19, 64×65; палитры до 64), цветовые tie/blue regression,
отверстие, контрастный тонкий штрих, прозрачность и принудительный CPU fallback.
Реальный worker, сохранённое состояние, блокировка устаревшего экспорта и категория
фото расширенного мастера проверены. 14 конфигураций синтетического корпуса:
обычные режимы не изменяются при включении опции, два фото проходят новую
сегментацию с 8 цветами на трёх качествах с одинаковыми CPU/GPU SVG.
Для четырёх пользовательских сравнений SVG CPU/GPU также совпали полностью.
Portable worker выдал тот же SVG, что исходники, при фактическом OpenCL GPU.
WASM не изменялся.
