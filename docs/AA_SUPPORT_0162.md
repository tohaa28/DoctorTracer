# Windows 0.14.1 / WASM 0.16.2: тёмные контуры ограниченной палитры

28.10.2026. Исправлена ошибка назначения цветов рисунков со сглаженными краями. Старый шаг искал в радиусе трёх пикселей близкие к палитре образцы (RGB SSE < 576) и запрещал остальные цвета. В затенённом красном/жёлтом участке подходящего образца могло не быть, а соседний чёрный оставался разрешённым. Он вытеснял более близкий цвет, утолщая контуры и превращая участки перьев в чёрные пятна.

Теперь такое ограничение разрешено только при наличии двух локально подтверждённых цветов, смесь которых объясняет наблюдаемый пиксель с RGB SSE ≤ 64. В остальных случаях сохраняется ближайший цвет палитры. Проверка проекции вычисляется целочисленно: e²·d² − (e·d)² ≤ 64·d², 0 < e·d < d². Используется 64-битная арифметика, одинаковая в NumPy, OpenCL и Rust; float-расхождений GPU здесь нет. Явные RGB палитры не меняются. Фотографический spatial-путь не меняется.

На предоставленном прозрачном изображении: для трёх/четырёх/пяти RGB-красок площадь тёмной метки изменяется 46107→37890, 45499→37880, 40185→35312 пикселей. В интерфейсе прозрачность занимает дополнительный слот: проверены и 4/5 слотов вместе с прозрачностью, и 4/5 RGB-красок. Это устранение ошибочного расширения, а не целевое уменьшение любой чёрной линии. Картинка, имя файла и палитра не зашиты в алгоритм.

tests/aa_support.py + .mjs проверяют затенённый цвет, прозрачность и настоящую смесь чёрного/белого, которую по-прежнему нужно отличать от посторонней серой краски. CPU/OpenCL/Rust дают одинаковые метки. Готовый EXE на двух палитрах даёт точный SVG исходного кода с действующим OpenCL. Полный Rust/WASM результат на предоставленном изображении: RGBA MAE 0.000114 / 0.000117 относительно Windows (допуск 0.25).

Повторены восемь прежних публичных рисунков/схем в обеих версиях с настоящими эталонами VM: нет пороговых регрессий. Дополнительно quality_refinement (8 случаев, 4 GPU fit), curves_parity (18), проверки отсутствия квадратных разрезов и PDF. Числа: [AA_SUPPORT_0162_RESULTS.json](AA_SUPPORT_0162_RESULTS.json). Изображения пользователя и локальные сравнения в Git/релиз не включены. Остальные ограничения прежних preview сохраняются.
