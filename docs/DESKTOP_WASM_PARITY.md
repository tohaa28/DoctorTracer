# Desktop WASM 0.12: проверка соответствия

Предыдущий независимый алгоритм 0.11 заменён переносом алгоритмов DoctorTracer Desktop.
Это сравнение с нашим десктопным приложением, не доказательство идентичности Vector Magic.

## Что перенесено

Photo: bilateral → joint spatial/colour mode filter → OpenCV-совместимые kmeans++
и медианы палитры → checkerboard spatial assignment → очистка → компоненты →
Ward-SSE объединение соседей → общий граф границ → совместное сглаживание → кривые.
Ограниченная палитра и графика: те же подготовительные этапы, Potrace 1.16,
Skia PathOps, Clipper 6.4.2 и проверка видимой геометрии.

WebGPU выполняет bilateral, пять итераций цветовых мод и пространственное
назначение палитры. Графы, Potrace и операции над кривыми выполняются в WASM.
Включение GPU не означает выполнение каждого этапа на видеокарте.
CPU fallback сохраняет алгоритм. Все вычисления выполняются на устройстве.

Маленькие замкнутые контуры до 8 рёбер закреплены при сглаживании и сохраняют
пиксельную границу: исчезновение однопиксельных отверстий исправлено в Python и Rust.
Предпросмотр использует совместное покрытие областей, устраняя прозрачные швы.

## Регрессионные проверки

`python scripts/verify_wasm.py --image image1.jpg --image image2.png` строит
эталоны десктопным Python-кодом, запускает настоящий WASM через Node и независимо
растеризует/проверяет геометрию результатов средствами десктопного приложения.
Данные входов и промежуточные векторы остаются в игнорируемом build/.
Агрегированные измерения: [JSON](desktop-wasm-results.json).

18 автоматических случаев: четыре синтетических изображения и два пользовательских
изображения (568×960 и 800×954), каждое при трёх уровнях качества.
Фильтры, палитры и очищенные метки совпадают побайтно. Максимальная ошибка RGBA
после растеризации — 0.00007535 в шкале 0–255 (допуск теста 0.02).
В независимой проверке пересечений этих случаев максимальная площадь — 0 px².

20 случаев ограниченной палитры включают прозрачность, три типа входа,
три качества и два фото с палитрой 9 цветов. Максимальная RGBA MAE — 0.14419/255
(допуск 0.25). Проверки пересечений проходят порог 0.0001 px².
Различия здесь обусловлены аппроксимацией и геометрическими операциями разных сборок.

Для среднего качества автоматического фото ошибка RGB на белом фоне относительно
десктопа снизилась с 5.93182 до 0 на первом фото и с 9.24363 до 0.00007469
на втором. Эти результаты относятся к двум контрольным изображениям.

Браузерная проверка `web/diagnostics.html` проверяет 12 случаев bilateral,
12 поиска цветовых мод и 36 пространственного назначения (GPU/CPU), прозрачность,
PDF Forms и мастер на четырёх размерах окна. При отсутствии WebGPU число GPU-тестов
равно нулю: такой результат не подтверждает проверку GPU.
Размеры берутся из Qt: панель 350 px, карточка 311×100, заголовок 30, навигация 43.
`tests/ui_desktop_reference.py` повторно экспортирует эталонные размеры.

## Экспорт и ограничения

SVG содержит группы цветов. PDF содержит главную Form-группу, цветовые Form-подгруппы
и отдельные связные кривые с отверстиями; тесты проверяют структуру и xref.
Повторный ручной импорт этой сборки PDF в CorelDRAW не является частью приведённых
автоматических измерений. EPS и PNG также доступны.

Полная идентичность на произвольных изображениях не гарантирована. Прозрачность
пороговая (128/255), вход ограничен стороной 2400 px. Для графики двойное
суперсемплирование применяется только до 2 млн пикселей и стороны 2048; выше
используется одинарное разрешение. При неудаче Skia применяется Clipper-разбиение.
Редактор браузера заменяет цвета и удаляет векторные области; полной пиксельной
кисти десктопного редактора в нём нет. Системные диалоги и выбор папки зависят
от браузера. Windows EXE этим выпуском не заменяется.
