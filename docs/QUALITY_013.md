# Windows 0.11 / WASM 0.13: детали и общие границы

Изменения алгоритма проверены на 42 входах и 84 эталонах Vector Magic 1.15.
Синтетические варианты коррелируют, реальных входов два и они ранее использовались.
После просмотра отчётов holdout уже нельзя считать слепой независимой оценкой.

## Изменения

- Фото с ограниченной палитрой используют общий граф цветовых границ. Ранее
  независимые маски Potrace и булевы вычитания оставляли мелкие прозрачные просветы.
- Для фиксированных цветов уменьшены диффузия координат и допуск упрощения:
  проходы 4/2/1 вместо 10/8/5, допуск общий ×0.5. Соседи используют одну кривую.
- WASM больше не включает агрессивную медианную очистку без запроса. Это согласовано
  с базовым Windows-мастером. Явный artifact_strength остаётся доступен в API.
- GPU фильтрация и назначение цветов используются также перед общим графом
  ограниченной фотографической палитры; graph/curves/audit остаются на CPU/WASM.
- SVG/PDF группировка и PDF по умолчанию сохранены. Графика AA/hard сохраняет
  Potrace/Skia/Clipper-путь. Старый Windows photo/Potrace доступен с backend=potrace
  или отключённым photo_regions. В WASM фотографии используют общий граф.

## Поправка к первому стенду

В первом baseline стенд задавал Desktop spatial_strength=700 для unlimited,
а Rust использовал 200. Также стенд принудительно включал artifact_strength=2,
хотя базовый Windows-мастер его не включает, и не передавал .24 допуска кривых
при среднем качестве (у CLI default .2). Эти сравнения не были точным отображением
одинаковых настроек мастера. Исторические файлы не переписаны; старые пять
расхождений нельзя объявлять пятью доказанными дефектами алгоритма.

Исправлен перевод профиля: auto-photo 200 / fixed-photo 700, cleanup=0,
curve_tolerance=.12×4/2/1. **До изменения кода** повторно сняты результаты старых
Desktop 0.10.3 и WASM 0.12.1 на тех же настройках запроса. Старый WASM игнорировал
cleanup=0 и всегда использовал 2; новый уважает его. Новые измерения сравнивают
одинаковые конфиги запроса и настоящие старые/новые движки, не прежний ошибочный CSV.

## Результаты относительно Vector Magic

Средняя RGB MAE на белом, шкала 0–255; по 42 случаям каждого профиля:

| Профиль | Windows до → после | WASM до → после |
|---|---:|---:|
| Photo / Medium / Unlimited | 5.11658 → 5.11658 | 5.90659 → 5.11661 |
| Photo / Medium / 9 colours | 8.60307 → 7.21740 | 8.53842 → 7.21742 |

Limited-палитра: улучшение среднего цвета 16.11% Windows и 15.47% WASM.
Unlimited WASM: 13.37%. Windows unlimited не изменён.
Это средние на данном наборе, а не универсальное обещание.

Пример thin-lines-02: fixed Windows MAE примерно 8.607 → 3.991; тонкие линии
WASM unlimited примерно 16.9 → 6.25. В отдельном тесте сегментации сохраняется
5246 тёмных пикселей против 2285 при включённой прежней медианной очистке.
Это счётчик сохранённой детали, не самостоятельная метрика совпадения с оригиналом.

## Проверки и оставшиеся предупреждения

- 84 случая Desktop/WASM на новых настройках: gate сопоставимости пройден,
  без ошибок обработки и пропущенных эталонов.
- 18 staged photo parity случаев (синтетика + два изображения, три качества):
  фильтры/палитры/метки идентичны, максимальный RGBA MAE конечного рендера
  0.00007535/255; независимый аудит пересечений пройден.
- 18 synthetic palette случаев на трёх качествах: shared photo и retained graphic
  paths проверены отдельно, допуски пройдены.
- Browser: 12 bilateral, 12 modes, 36 assignment GPU/CPU; проверены окончания
  shared photo и fixed photo, четыре размера мастера/экспорта. Portable EXE worker
  реально выполнил новый fixed-photo путь. PDF group/xref и thin-detail тесты прошли.

**Gate качества относительно предыдущей версии не полностью зелёный.**
У Windows отмечены texture-05/fixed и watercolor-04/fixed: цветовая ошибка уменьшилась,
но boundary F1 снизился больше 0.01. У WASM отмечены alpha-03/auto (IoU снизился
на ~0.0029), watercolor-04/fixed и watercolor-05/auto (boundary F1).
Допуски не ослаблялись, предупреждения сохранены. Это preview, не полное совпадение
с Vector Magic и не улучшение каждой метрики каждого изображения.

Агрегаты без изображений: [quality-013-results.json](quality-013-results.json).
Локальные полные отчёты: build/quality/reports/desktop-quality-v3 и wasm-quality-v3;
источники: runs/desktop-v0103-correct-settings, wasm-v0121-correct-settings,
desktop-detail-v3, wasm-detail-v3. Входы и SVG оригинала не публикуются.
Следующее направление — выбор палитры/сегментация сложных цветов, полупрозрачность
и независимый силуэт, с сохранением текущей общей геометрии.
