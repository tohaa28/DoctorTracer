## Цель и накопленные требования

Пользователь запросил локальное Windows-приложение, максимально похожее на
Vector Magic Desktop Rus 1.15 по мастеру и качеству векторизации. Исследование
оригинала выполнялось через REA и интерфейс; DoctorTracer — независимая реализация.
После разработки Windows пользователь разрешил публикацию в tohaa28/DoctorTracer
и поручил выпустить WASM, попробовав Rust. Первоначальная WASM была отложена
ради качества Windows, затем возобновлена после принятия результата.

Требования, действующие при продолжении:

- Сравнивать одинаковый вход при одинаковых типе изображения, качестве,
  прозрачности и палитре. Особенно важен базовый режим с ограниченной палитрой.
- Устранять блоки, ступеньки, швы, исчезающие цвета, наложения и потерю отверстий.
- SVG группировать по цвету. После импорта PDF в CorelDRAW: основная группа →
  подгруппы RGB → отдельные связные кривые с отверстиями.
- Использовать GPU там, где сохраняется качество, проверять CPU/GPU и полное время.
  Пожелание «GPU для всех расчётов» полностью не реализовано.
- Повторять десктопный мастер и выравнивание кнопок, показывать процент обработки,
  помещать все элементы экспорта в панель, использовать понятные иконки.
- WASM должен использовать десктопные алгоритмы и оформление.
- Последнее функциональное изменение: PDF — исходный формат быстрого сохранения,
  перетаскивания и Windows Save As. Растровый экспорт остаётся PNG.
- Изображения пользователя и их эталоны не публиковать вместе с исходниками.

В работе использованы изображения: мультяшный персонаж с увеличительным стеклом,
акварельный лев 800×954, фотография зелёной фигурки 568×960 и снимок сравнения
увеличенного глаза льва. Это ограниченный контрольный набор, не независимый корпус.

## Хронология

### До и включая 0.5: исходный Windows и отдельный WASM (24.10)

Созданы Qt/PySide6-мастер, обработка изображений, экспорт и раннее отдельное
C++/Emscripten-ядро для браузера. Фоторежим опирался на VTracer; графика — на Potrace.
История до первого Git-коммита представлена только документацией и handoff.
Первый сохранённый коммит `5abe9a9` уже содержит Windows и WASM-прототип.

0.5/0.5.1: пространственная предобработка и сокращение мелких областей улучшили
сравнение с оригиналом на одном изображении. Ошибки на белом/тёмном фоне,
число путей и времена приведены в [COMPARISON.md](COMPARISON.md).
Ограничения частичной альфы и отличия геометрии остались.

### 0.6: менее ступенчатые кривые (24.10)

`3d9275a`: области фото повторно аппроксимируются native Potrace DLL.
Кривые стали плавнее, но появилась дополнительная стоимость CPU.
Результаты и отвергнутые варианты: [CURVES.md](CURVES.md).
Релиз v0.6.0 сохранён как прежняя точка отката и остаётся GitHub Latest.

### Переданный исследовательский пакет (24.10)

Пользователь передал START_HERE.md и полный handoff: инженерные конспекты,
синтетические входы, OpenCL-варианты, CPU/parity-проверки, планы GPU-испытаний,
контрольные суммы и прежние архивы. Это материалы исследований, не полный checkout.
На момент создания пакета не было измерений GTX 1080/RTX 3050; последующие
локальные проверки нельзя задним числом приписывать этому пакету.

### 0.7 и 0.8: цвета, пространственная сегментация, геометрия (24.10)

`e1247d2`: устранена потеря цветов при больших SVG compound paths в Qt;
введён OpenCL пространственный классификатор фиксированной палитры с CPU fallback.
`dbbdcf2`: группы SVG по RGB, удаление закрытой геометрии, целочисленный аудит
пересечений. `90a3538`: зафиксирована цена линейного fallback для сложных изображений.
Документы: [SPATIAL_PALETTE.md](SPATIAL_PALETTE.md), [VECTOR_LAYOUT.md](VECTOR_LAYOUT.md).
Номера 0.7–0.9 обозначали этапы preview; отдельные публичные теги есть не для всех.

### 0.9: объединение цветов и PDF/Corel (25.10)

`459ef53`: геометрия одного RGB объединяется, добавлены иконки и GPU bilateral.
Первоначальный PDF давал составной объект на цвет, но ещё не требуемую вложенную
структуру групп CorelDRAW. Исторические проверки: [COREL_IMPORT.md](COREL_IMPORT.md).

`884e017`: Rust/visioncortex, WebGPU-фильтрация, браузерный мастер, группированный

### 0.12 Desktop WASM: перенос рабочего алгоритма (25.10)

`5e398f9`: visioncortex удалён из текущего Rust-ядра. Перенесены десктопные
фильтры, OpenCV-совместимая палитра, пространственное назначение, объединение
соседей, общий граф границ и кривые. Ограниченная палитра/графика использует
Potrace 1.16, Skia PathKit и Clipper 6.4.2.

Исправлены ориентация Potrace, точное 2× INTER_LINEAR, winding отверстий,
исчезновение маленьких замкнутых контуров; последняя правка зеркально внесена
в Python и Rust. Введены native WASM аудит и fallback видимого разбиения.
Добавлены RGB-палитры, сегменты, редактор удаления областей, batch ZIP,
SVG/PDF/EPS/PNG и совместный предпросмотр. Иконки собственные, из DoctorTracer
Desktop; размеры карточек измерены в Qt, закрытые ресурсы оригинала не включены.

Результаты: 18 автоматических и 20 limited-palette случаев. Автоматические
фильтры/палитры/метки побайтно совпадают с десктопом; максимальная RGBA MAE
итогового рендера 0.00007535/255. Для ограниченной палитры — 0.14419/255.
Проходят геометрические допуски. 12 bilateral, 12 mode и 36 spatial GPU/CPU
проверок; мастер/экспорт на четырёх размерах окна. Это соответствие DoctorTracer
Desktop на контрольном наборе, не доказанная идентичность Vector Magic.
Полная методика: [DESKTOP_WASM_PARITY.md](DESKTOP_WASM_PARITY.md).

`8e0f67d`, `4bd2745`: исправлена Unicode-подпись и обновлены ключи кеширования,
чтобы браузер не смешивал старый JS с новым WASM ABI.

### PDF по умолчанию: Windows 0.10.3 / WASM 0.12.1 (25.10)

`eccf5c9`: PDF первым в быстром сохранении и drag export обеих версий;

## Состояние доказательств и оставшиеся различия

Полная идентичность Vector Magic не достигнута и не измерена на независимом
корпусе. CPU остаётся в графах и геометрии; в браузере это WASM Worker.
Альфа пороговая 128, браузер уменьшает вход до стороны 2400. Двойное разрешение
графики ограничено размером. Нет полной десктопной пиксельной кисти в браузере.
Текущий WASM PDF проверен автоматически и скачиванием; ручной Corel-импорт
именно этой последней сборки не следует считать выполненным по старым тестам.
Прежние отрицательные результаты сохраняются в FAILED_APPROACHES.md.

Полный доступный журнал коммитов/релизов, SHA и ссылки зафиксированы
в [development-snapshot.json](development-snapshot.json).
