# Выравнивание готовых контуров

Windows **0.18.0-preview**, WASM **0.20.0-wasm-preview**, 29.10.2026.

Новый инструмент **«Выравнивание контуров…»** доступен на страницах обзора и сохранения. Он подгоняет длинные общие участки целиком, чтобы убрать мелкую волнистость.

Независимые настройки: выпрямление почти прямых участков, подгонка плавных кривых и защита углов. Допуск 0–2 пкс исходника, начальное значение **0,15 пкс**; ноль возвращает исходный вектор. Есть предпросмотр, сброс, применение и общая история отмены с другими модулями. Показаны числа прямых участков, подогнанных дуг и узлов до/после. Исходный растр для этой операции не нужен; основная трассировка сохранена.

## Метод

В `post_clean.rs` используется общий граф примитивов. Новый режим выделяет максимальные цепочки между стыками и настоящими углами. Угол оценивается в пространственном окне 2,5 пкс: короткий пиксельный перегиб не должен становиться важным углом. Рамка и стыки фиксируются.

Почти прямой участок заменяется единым отрезком. Для плавных цепочек рассчитывается глобальная кубическая аппроксимация методом наименьших квадратов с параметризацией по длине. Если весь участок не помещается в допуск, он делится и подгоняется по частям. Касательные совместимых стыков согласуются, если обе дуги после этого остаются в допуске. Исходные образцы сохраняются: объединения внутри операции не накапливают ошибку.

Новый примитив регистрируется один раз; соседние цвета используют его в противоположных направлениях. Заливки и цветовые группы сохраняются. Мелкие гладкие циклы до 4 пкс и компактные овалы сохраняются. Для длинных цепочек ограничена глубина подгонки; длинная прямая проверяется глобально.

Защита площади каждого контура допускает не более 20% изменения и запрещает переворот или схлопывание. Независимый аудит проверяет пересечения. При отказе допуск уменьшается вплоть до исходного результата; уменьшение видно в окне. Отклонение оценивается в обе стороны на дискретизированных кривых с внутренним запасом 20%. Это не строгая аналитическая граница Хаусдорфа для произвольного SVG.

Один Rust-код используется Windows DLL и WASM. Расчёт выполняется на CPU в фоне интерфейса. Поддерживаются закрытые M/L/C/Z-контуры DoctorTracer. Контуры не растрируются заново, элементы не удаляются; для удаления островков остаётся отдельный модуль очистки.

## Проверки

[Машинный отчёт](REGULARIZE_020_RESULTS.json). `tests/regularize.py` → `tests/regularize.mjs`: одинаковый входной SVG даёт побайтно одинаковый результат Windows/WASM.

- Волнистая общая граница: **86 → 8 узлов**, один общий отрезок с совпадающими сторонами.
- Длинная граница: **2006 → 8 узлов**, проверка ограничения рекурсии.
- Шумная парабола: **33 → 5 узлов**, две кубические дуги. Независимая проверка по 201 точке каждой дуги удержала отклонение от аналитической параболы ниже 0,25 пкс.
- Почти прямой кубик заменяется отрезком при выключенной подгонке кривых. Проверены раздельные режимы, их отключение и нулевой допуск.
- Острые звёзды и маленький квадрат возвращаются без изменения. Тонкая линза не схлопывается: допуск автоматически уменьшается.
- **NF: 720 → 432 узла (−40%)**, 28 прямых участков и 47 подогнанных дуг, около **0,03–0,04 с** на Windows. Четыре звезды и четыре овальных контура сохранены геометрически точно. Аудит не обнаружил пересечений.
- При одинаковом Poppler-рендере PDF в 10× IoU синей маски с присланным Vector Magic: **96,651% → 96,670%**. Это небольшое изменение на одном примере, а не обещание улучшить совпадение на всех изображениях. Более сильное выравнивание может заметнее менять форму. Полной идентичности Vector Magic нет.

Диалог проверен отдельным тестом: предпросмотр, отмена, применение, снимок отката, сброс и закрытие во время расчёта. Повторены тесты очистки, сглаживания, парных границ, AA-палитры и PDF-группировки. Приватные исходники и результаты пользователя не публикуются.
