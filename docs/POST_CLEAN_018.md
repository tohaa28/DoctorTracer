# Очистка и упрощение готовых векторов

Windows **0.16.0-preview**, WASM **0.18.0-wasm-preview**, 28.10.2026.

После трассировки нажмите **«Очистка и упрощение…»** на странице обзора или сохранения. Два независимых параметра:

- **Площадь островков**, пкс² исходного изображения: удаляет замкнутые мелкие островки и отверстия. По умолчанию 4; 0 отключает удаление.
- **Допуск упрощения**, пкс: объединяет участки кривой и уменьшает число опорных узлов. По умолчанию 0,25; 0 отключает упрощение.

Защита углов и тонких элементов включена. Предпросмотр можно отключать для сравнения. «Сброс» обнуляет оба параметра. «Применить» создаёт запись для отмены; «Отмена» возвращает результат на момент открытия окна. Оба дополнительных модуля используют общую историю отката. PDF остаётся форматом экспорта по умолчанию.

## Метод

Обработка выполняется непосредственно над закрытыми абсолютными M/L/C/Z-контурами текущего DoctorTracer, без повторного растрирования, сегментации и подбора палитры. Одно Rust-ядро используется Windows DLL и WASM. CPU-операция работает в фоне интерфейса; имеющееся GPU-ускорение основной трассировки сохранено.

**Удаление островков:** строится граф общих примитивов. Можно убрать только целиком замкнутую изолированную границу. Она одновременно удаляется у всех владельцев: цветовой островок заполняется окружением, маленькое отверстие закрывается. Изолированный объект на прозрачном фоне исчезает. Цвета оставшихся областей не пересчитываются. Группы сохраняются; цвет без объектов не создаёт пустую PDF-подгруппу.

Границы со стыками трёх и более участков сохраняются независимо от флажка защиты: их удаление без перестройки топологии оставило бы разрывы. Рамка также сохраняется. При включённой защите островки с отношением сторон больше 8 не удаляются. Счётчик «защищено» показывает мелкие контуры, которые не удалось безопасно убрать. Это намеренно консервативная очистка, а не обещание удалить каждую малую область.

**Упрощение:** соседние участки общей границы объединяются в отрезок либо кубическую кривую Безье. Концы и касательные подгонки фиксируются. Исходные образцы сохраняются на протяжении нескольких объединений, чтобы ошибка не накапливалась. Кандидат сравнивается с исходной дискретизированной кривой в обе стороны. Узлы стыков не перемещаются; включённая защита сохраняет повороты больше 25°. Один результат записывается соседним цветам в обратных направлениях, поэтому независимых расходящихся контуров не возникает.

Перед применением проводится штатный независимый аудит пересечений. При его отказе допуск уменьшается до пяти раз, затем проверяется вариант только с удалением островков. При полном отказе остаётся исходный результат. Допуск проверяется по дискретизированной геометрии; это не строгая аналитическая граница Хаусдорфа для произвольного SVG. Модуль не предназначен для сторонних SVG с трансформациями и другими командами.

## Результаты

[Машинный отчёт](POST_CLEAN_018_RESULTS.json).

- 9 синтетических случаев и один локальный готовый вектор: Windows/WASM дают побайтно одинаковый SVG.
- Общая прямая граница: 106 → 8 узлов без изменения формы.
- Окружность: 8 → 4 кубические дуги; независимая проверка по 201 точке каждой дуги удержала радиальную ошибку ниже 0,25 пкс. У общей окружности обе стороны имеют одинаковые четыре кривые.
- Площадь учитывает viewBox; проверены островок внутри заливки, отмена удаления, тонкий штрих, защита стыков и прозрачность удалённого отдельного объекта.
- Готовый вектор попугая при 4 пкс² / 0,25 пкс: **11 106 → 4 419 узлов (−60,2%)**, удалено **30** островков, защищено **280** малых контуров, около **0,59 с** на Windows. Пересечений цветов аудит не обнаружил. Полный растр 1024×1536: средняя абсолютная разница RGBA **0,0301/255**; затронуто **0,2975%** пикселей. Это сравнение до/после очистки, не новая оценка равенства Vector Magic.
- Узлы здесь считаются по цветовым контурам: общая граница учитывается у каждого владельца. Показатель соответствует упрощению экспортируемых кривых, а не числу уникальных вершин общего графа.
- `tests/post_clean.py`, `tests/post_clean.mjs`, `tests/post_clean_dialog.py`; повторены `post_smooth`, `shared_contract`, `aa_support`, `pdf_color_groups`.

Исходные пользовательские изображения, SVG и снимки их результата остаются локально и не включены в репозиторий или релизы.
