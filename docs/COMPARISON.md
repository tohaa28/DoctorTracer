# Сравнение 0.4 и 0.5

Эталон: Vector Magic Desktop Rus 1.15, базовый мастер, фотоснимок, сохранение прозрачности, цвета без ограничений. Экспортированы отдельные SVG высокого, среднего и низкого качества. Вход 800×954 RGBA; SHA-256 в `photo-comparison.json`. Изображение и эталонные экспорты остаются локально.

Оба SVG растеризованы Qt SVG при одинаковых 800×954 пикселях независимо от физических единиц. MAE — средняя абсолютная ошибка RGB после композиции на белый (255) и тёмный (40) фон. IoU — пересечение/объединение альфа-силуэтов при пороге 128. Эти метрики не означают идентичность узлов или топологии.

| Качество | Контуры оригинала | 0.4 | 0.5 | MAE белый 0.4 → 0.5 | MAE тёмный 0.4 → 0.5 |
|---|---:|---:|---:|---:|---:|
| Высокое | 7791 | 18965 | 9220 | 9.236 → 8.804 | 12.238 → 8.809 |
| Среднее | 3228 | 15176 | 3615 | 9.637 → 9.436 | 12.714 → 9.469 |
| Низкое | 702 | 8839 | 952 | 12.459 → 11.711 | 15.548 → 11.885 |

Изменения: пространственное объединение близких цветов до VTracer, зависимое от качества удаление мелких областей, сохранение прямого RGB вместо сведения полупрозрачных пикселей с белым, бинарная альфа. Эталонные цвета и геометрия при трассировке не используются. Проверены 43 конфигурации; параметры подобраны на одном изображении и требуют независимого корпуса для проверки обобщения.

Одиночные замеры полного вызова движка без запуска интерпретатора: высокое 4.79 → 3.29 с; среднее 3.81 → 2.66 с; низкое 2.64 → 2.44 с. Это не статистический бенчмарк. OpenCL здесь не участвует; ускорение даёт сокращение числа областей и кривых.

Ограничения: оригинал сохраняет частичную непрозрачность некоторых областей, DoctorTracer использует бинарную альфу. Отличаются границы, репрезентативные цвета и кривые. Физические единицы: оригинал pt, DoctorTracer px. Для логотипов сохранён путь OpenCL + Potrace. WASM — отдельное ограниченное ядро, в эти метрики не входит.

Для дальнейшего сближения необходимы общие границы соседних регионов, восстановление частичной альфы, пространственный кластеризатор со стабильными региональными цветами и независимые изображения для валидации.
