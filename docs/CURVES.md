# Windows 0.6: исправление ступенчатых границ

Сравнение выполняется при одинаковых настройках: фото, сохранение прозрачности, неограниченные цвета; отдельные эталоны высокого/среднего/низкого качества из установленной Vector Magic Desktop Rus 1.15. При увеличении старый фотографический движок сохранял множество коротких угловатых участков даже в режиме spline. Обычная ошибка RGB по всей картинке недостаточно характеризовала этот дефект.

Теперь каждый цветовой регион проходит дополнительную аппроксимацию: исходный векторный контур растеризуется с учётом покрытия пикселей, затем native Potrace строит и оптимизирует длинные кубические кривые. Цвета и порядок слоёв сохраняются. Исходное изображение на этом этапе не размывается. Допуск кривых зависит от качества: 0.25 / 0.4 / 0.6 пикселя; alphamax 1.2. DLL вызывается внутри рабочего процесса, без запуска отдельного EXE для каждой области.

Проверены увеличенные фрагменты глаза при настоящей векторной растеризации в масштабе 400%, полные изображения, прозрачность и экспорт. Пробовались усиление corner/splice-порогов VTracer, изменение предварительной цветовой фильтрации, перекрашивание регионов по исходнику, Gaussian-фильтрация масок и обрезка перекрытых областей. Эти варианты не включены: ухудшали форму, цвета либо давали щели.

Итоговые измерения по трём качествам находятся в `curve-comparison.json`. Они показывают небольшое улучшение RGB MAE; главное изменение оценивается на увеличенных векторных границах. Эталонные изображения и пользовательские файлы остаются локально.

**Ограничение:** это исправление геометрии, а не воспроизведение закрытого алгоритма сегментации. Регионы, оттенки и некоторые мелкие детали всё ещё отличаются. Соответствие требованию «не хуже оригинала» на произвольных изображениях пока не подтверждено. Не следует выводить его из одной общей метрики.

Полная обработка контрольной акварели 800×954 занимает около 6.2 с на высоком, около 4 с на среднем и 2.8 с на низком качестве без учёта запуска интерпретатора; новый этап добавляет около 3.1 / 1.5 / 0.5 с соответственно. Качество здесь приоритетнее скорости. GPU в этом этапе не используется.

Проверки: `python tests/photo_curves.py` (синтетический силуэт IoU 0.992, кривые, прозрачность, внутренний белый цвет, нечётная ширина bitmap, ориентация, детерминизм) и `python tests/desktop_smoke.py`. Сборка DLL: официальный Zig 0.15.2 на PATH, `python scripts/build_potrace_dll.py`. Исходники Potrace и native SVG adapter включены; Windows-сборка с DLL распространяется по GPL-3.0-or-later. Ранее выпущенная WASM-версия не изменялась.
