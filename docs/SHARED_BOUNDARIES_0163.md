# Windows 0.14.2 / WASM 0.16.3: общие границы без геометрических щелей

28.10.2026. В переданном PDF подтверждены реальные внутренние незаполненные участки, а не только сглаживание просмотрщика. Например, один узкий участок площадью около 10.81 px² находится целиком в области исходного изображения с alpha ≥ 250. Прежнее устранение наложений не было проверкой полноты покрытия.

## Изменение алгоритма

Основная графическая трассировка больше не подгоняет маски цветов независимо. Все цвета и прозрачность образуют грани одного планарного графа. Сглаживание, упрощение и контрольные точки Безье общие для соседей. Невидимая внешняя грань участвует в проверке, но не рисуется. Фотографический общий граф получает ту же проверку. Уточнение общей кривой по растру вычисляется в каноническом направлении, затем зеркально записывается соседу: независимое округление двух сторон исключено.

Перед выдачей результата каждый сериализованный примитив должен иметь ровно двух разных владельцев, совпадающие координаты/контрольные точки и противоположный обход. Это точный контракт, без допуска по площади для несовпадения границ. Если сглаживание не проходит контракт, используется проверенный общий полигональный граф; возвращаться к независимым маскам нельзя. Проверка пересечений остаётся дополнительной. Координаты рамки изображения закреплены. Точные пиксельные цвета и длинные прямоугольные интерфейсы сохраняются без скругления, включая QR-модули; проверки имени файла нет.

PDF/EPS учитывают общий viewBox и единое масштабирование всех цветов. PDF остаётся чисто векторным, с подгруппами по цветам, без маскирующих обводок и добавленных перекрытий. Представление SVG и PDF проверено по полному набору примитивов. Настоящая прозрачность исходника сохраняется; пустоты фона не закрашиваются произвольно.

## Проверки

На предоставленном изображении 6000 пар общих рёбер, несовпадений 0. В исправленном PDF все 5106 внутренних примитивов совпадают со SVG; четыре цветовые группы сохранены. PDF отрисован Poppler при 144 dpi и просмотрен полностью и в увеличении. Пользовательские файлы и исправленный PDF в Git/релизы не включены.

`tests/shared_contract.py` + `.mjs`: прозрачность, отверстия, трёхцветные стыки, тонкие участки, гладкие/полигональные режимы, CPU/GPU/Rust. Намеренное смещение координаты на 0.0001 и одинаковое направление обхода отвергаются. `tests/export_viewbox.mjs` и Poppler проверяют масштабированный/смещённый PDF и EPS, сохранение векторных групп. Дополнительно quality_refinement, curves_parity, photo_regions, photo_detail, joint_raster, AA-support и PDF-группы.

Повторены восемь публичных рисунков и схем с настоящими эталонами VM в обеих версиях: пороговых регрессий нет; QR сохраняет MAE 0. Это целевой набор проверок, а не повтор всех прежних 72 режимов. Промежуточный вариант скруглял QR; общий критерий прямоугольной геометрии устранил это без привязки к изображению. Числа: [SHARED_BOUNDARIES_0163_RESULTS.json](SHARED_BOUNDARIES_0163_RESULTS.json).

Контракт проверяет геометрию. Отдельный PDF-просмотрщик может отображать тонкий шов сглаживания даже на математически совпадающих рёбрах; это проверено отдельно на двух точных треугольниках. Геометрические зазоры не маскируются перекрытиями. Остальные известные ограничения preview сохраняются.
