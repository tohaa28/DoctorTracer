# Windows 0.14 / WASM 0.16

27.10.2026. Сравнение с Windows 0.13 / WASM 0.15, источник 086430b. Новые параметры качества зафиксированы в 88d2263 до оценки шести новых входов; их список зафиксирован ещё раньше, в 2388ad7. После оценки исправлялись скорость проверки геометрии и устойчивость, без подбора параметров палитры по новым результатам.

## Алгоритм

Автоматическая ограниченная палитра теперь уточняется после пространственной сегментации. До трёх раундов чередуют обновление цветов по внутренним пикселям областей и пространственное назначение. Изменение цвета ограничено шестью единицами канала за раунд. Принимаются только шаги, уменьшающие полную энергию RGB SSE + 700 × число границ соседей. Ручные RGB остаются неизменными. Для почти одномерного цветового распределения используется частотная палитра; это устраняет ухудшение Chelsea без проверки имени изображения.

Общие кубические границы дополнительно выбираются по независимой растеризации полного изображения: четыре субпиксельных отсчёта по каждой оси до мегапикселя, два выше. Проверяются три общих натяжения 0.75 / 1 / 1.25; сохраняется только снижение RGB SSE + 3 × alpha SSE относительно рабочего фильтрованного растра. Концы общих границ закреплены. Это ограниченный глобальный поиск общего параметра, а не оптимизация всех контрольных точек. Windows вызывает тот же Rust через включённую DLL, браузер — через WASM. После выбора остаётся независимый аудит наложений и безопасный откат.

OpenCL / WebGPU выполняют поддерживаемые фильтры, пространственные назначения, выделение рёбер и функции покрытия; новые раунды пространственного назначения также используют GPU. Булева геометрия и независимый аудит остаются на CPU. При потере GPU выполняется проверенный CPU fallback. Полный перенос всех операций на GPU не заявляется.

Проверка сложных compound-контуров использует пространственные участки с сохранением отверстий и суммы пересечений для полной пары объектов. При площади около порога выполняется полная перепроверка. Допуск 0.0001 px² не ослаблен. Удалён неиспользуемый полный геометрический проход WASM перед обязательным разбиением. Поиск родителей отверстий фильтруется точными bounding box; критерий вложенности сохранён. Для сильно фрагментированных входов (>1000 исходных объектов и >12 участков) Windows вызывает тот же C++ целочисленный backend, что WASM. Проверка полных цветовых групп не повторяет квадратично аудит каждого из тысяч фрагментов. Такой же backend восстанавливает результат при аварии геометрического процесса. Целочисленное разбиение может аппроксимировать кривые; точность проверяется отдельно.

## Испытания

12 прежних входов × 4 режима и шесть новых × 4 режима. Все 72 эталона получены настоящим Vector Magic Desktop 1.15 с проверенными настройками. Прежний набор участвовал в разработке; новый мал и не доказывает статистическое обобщение. Профили по назначению отделены от стрессовых режимов. Данные и ограничения: [QUALITY_016_RESULTS.json](QUALITY_016_RESULTS.json). Локальный интерактивный отчёт: build/quality-release-016/index.html.

На прежнем наборе фото с девятью слотами: MAE относительно VM 8.015 → 7.025; Chelsea 8.096 → 5.764. Полного равенства с VM нет. Исходные изображения, экспорты VM и локальные скриншоты в релиз не включены. Манифест нового набора содержит ссылки, лицензии и хеши.

Прежняя WASM на новом наборе была остановлена из-за чрезмерного времени; полного before/after агрегата для неё нет. Для нового набора baseline — полный прогон прежней Windows, новая WASM сравнивается непосредственно с VM и Windows. Прерванные и ошибочные диагностические прогоны сохранены локально, не заменены успешными задним числом. Составной финальный прогон Windows явно хранит происхождение каждой строки.

Три чередующихся прогретых замера CPU/GPU текущего алгоритма: Chelsea 5.922 / 4.536 s (1.31×), astronaut 7.618 / 5.250 s (1.45×), SVG совпадают. Фоновые отчёты влияют на абсолютное время. Это не сравнение скорости с VM или прежней версией.

Проверки: joint_raster (монотонность энергии, ручная палитра, точное CPU/GPU SVG, потеря устройства, Rust/Python), quality_refinement, vector_partition, photo_regions, photo_detail, curves_parity, PDF-группы, палитра, audit_tiles (16 случаев, отверстия и пересечения около допуска). Два полных браузерных GPU Worker дали точное SVG и невозрастающую полную растровую ошибку. Исходник native Rust DLL собирается scripts/build_quality_native.py; C++ WASM аудит — scripts/build_audit_wasm.py.

## Известные отклонения финальной проверки

На новом наборе фото / 9 слотов MAE 5.378 → 5.004; фото / высокое / свободно 3.236 → 3.235. Hubble в стрессовом режиме рисунка ухудшается: MAE 3.578 → 5.082. На соответствующих типу входов профилях этой пороговой регрессии нет. Межверсионный допуск выдержан в 71/72 случаях; Camera / фото / среднее / свободно имеет RGBA MAE 0.743723 при допуске 0.02. Windows консервативно откатывает сглаживание после независимого Qt/Clipper аудита; браузерный аппроксиматор границ принимает иной вариант. Это известное расхождение, не доказанная идентичность. Все остальные 71 случая проходят. Неудачные диагностические прогоны и полный медленный C++ прогон сохранены; их геометрия не заменена задним числом.
